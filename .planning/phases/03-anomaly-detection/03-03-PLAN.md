  <action>
Create BaselineCalculator that orchestrates all anomaly detection methods from RESEARCH.md hybrid pattern.

Classification flow (from CONTEXT.md decisions):
1. Check for level shift first (sudden drops are immediately "exceptional")
2. If 30+ observations exist, use z-score classification
3. If <30 observations, use static threshold fallback
4. Apply seasonal adjustment to static thresholds when travel_date provided

Z-score tier mapping (from RESEARCH.md):
- z < -2.5: "exceptional" (also check absolute floor)
- z < -2.0: "great"
- z < -1.5: "good"
- else: None (not a deal)

Cold start handling (from CONTEXT.md):
- 2-week silent monitoring period for new routes
- A route with <14 observations gets method="silent_period", tier=None

Class structure:
```python
class BaselineCalculator:
    def __init__(self, db_client: TursoClient = None):
        self.db = db_client
        self.anomaly_detector = AnomalyDetector(window=90, min_periods=30, z_threshold=-2.5)
        self.level_shift_detector = LevelShiftDetector(short_window=3, long_window=14, threshold_pct=0.40)

    def classify_deal(
        self,
        price_cents: int,
        route: str,
        travel_date: datetime = None,
        cabin_class: str = "economy"
    ) -> dict | None:
        """
        Classify a price as a deal using hybrid detection.

        Returns:
            {
                "tier": "good"|"great"|"exceptional"|None,
                "method": "zscore"|"level_shift"|"static"|"silent_period"|"no_deal",
                "z_score": float or None,
                "drop_pct": float or None,
                "observation_count": int
            }
            or None if not a deal
        """
```

Standalone convenience function:
```python
def classify_deal(price_cents: int, route: str, travel_date: datetime = None, db_client: TursoClient = None) -> dict | None:
    """Quick classify without instantiating BaselineCalculator."""
    calc = BaselineCalculator(db_client)
    return calc.classify_deal(price_cents, route, travel_date)
```
