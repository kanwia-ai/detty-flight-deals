In anomaly/anomaly_detector.py, implement AnomalyDetector class from RESEARCH.md pattern:
- __init__(window=90, min_periods=30, z_threshold=-2.5)
- calculate_rolling_zscore(prices: pd.Series) -> pd.Series
- is_anomaly(z_score: float) -> bool
- detect(prices: pd.Series) -> dict with is_anomaly, z_score, method, rolling_mean, rolling_std

Key implementation details from RESEARCH.md:
- Use pandas rolling().mean() and rolling().std()
- Handle zero std by replacing with np.nan
- Return "insufficient_data" method when len(prices) < min_periods
- Z-score formula: (price - rolling_mean) / rolling_std
- Negative z-score means price below average (potential deal)
  </action>

```python
# Test with insufficient data
short_prices = pd.Series([1000, 1050, 980])

print("AnomalyDetector tests passed")
```

  <name>Task 2: Create SeasonalAdjuster with research-backed multipliers</name>
  <files>anomaly/seasonal_adjustments.py</files>
  <action>
Create SeasonalAdjuster class implementing DISC-07 from RESEARCH.md pattern.

SEASONAL_MULTIPLIERS dict (from research):
- January: 1.50 (Detty December spillover)
- February-May: 1.00 (shoulder seasons)
- June-August: 1.25 (summer vacation)
- September-November: 1.00 (shoulder/cheapest)
- December: 1.50 (Detty December peak)

Methods:
- get_multiplier(travel_date: datetime) -> float
- adjust_threshold(base_threshold: int, travel_date: datetime) -> int
  Multiplies threshold for seasonal comparison (e.g., $700 WOW in December becomes $1050)
- normalize_price(price_cents: int, travel_date: datetime) -> int
  Divides price to remove seasonal effects for cross-season comparison

All prices in CENTS (INTEGER) per Phase 2 decision.
  </action>
  <verify>
```python
from datetime import datetime
from anomaly import SeasonalAdjuster

# December should have 1.5x multiplier
dec_date = datetime(2026, 12, 15)
assert SeasonalAdjuster.get_multiplier(dec_date) == 1.50, "December should be 1.5x"

# Threshold adjustment
wow_threshold_cents = 70000  # $700 in cents
adjusted = SeasonalAdjuster.adjust_threshold(wow_threshold_cents, dec_date)
assert adjusted == 105000, f"December threshold should be $1050 (105000 cents), got {adjusted}"

# Price normalization
dec_price = 105000  # $1050 in cents
normalized = SeasonalAdjuster.normalize_price(dec_price, dec_date)
assert normalized == 70000, f"Normalized December price should be $700, got {normalized}"

# Summer should have 1.25x multiplier
jul_date = datetime(2026, 7, 15)

print("SeasonalAdjuster tests passed")
```
