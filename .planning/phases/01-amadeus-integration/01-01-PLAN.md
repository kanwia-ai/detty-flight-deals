<task type="auto">
  <name>Task 1: Create amadeus_client.py -- SDK wrapper with Cheapest Date Search + Offers Search fallback</name>
  <files>amadeus_client.py, requirements.txt</files>
  <action>
Create `amadeus_client.py` at project root with these components:

1. **create_amadeus_client()** function:
   - Uses `amadeus.Client()` from the SDK (NOT raw requests)
   - SDK reads AMADEUS_CLIENT_ID and AMADEUS_CLIENT_SECRET from env vars automatically
   - Set hostname from env var AMADEUS_HOSTNAME (default: 'test', switch to 'production' for real data)
   - Set log_level='warn' (use 'debug' for development)
   - Return the Client instance

2. **PRIORITY_ROUTES** constant:
   - List of tuples: [("JFK", "LOS"), ("EWR", "ACC"), ("ATL", "LOS"), ("IAD", "ACC"), ("DFW", "LOS"), ("IAH", "ACC")]
   - These are the 6 priority routes from the roadmap success criteria

3. **search_cheapest_dates(client, origin, dest)** function:
   - Calls `client.shopping.flight_dates.get(origin=origin, destination=dest)`
   - Returns list of dicts: [{"departureDate": str, "returnDate": str, "price_usd": int}, ...]
   - Parse price: `int(float(item['price']['total']))` (normalize to integer dollars immediately)
   - On ResponseError or empty data, return empty list
   - Log: "Cheapest Date Search {origin}-{dest}: {len(results)} dates found" or "no data (route not in cache)"

4. **search_offers_fallback(client, origin, dest, sample_dates)** function:
   - For each date in sample_dates, call `client.shopping.flight_offers_search.get(originLocationCode=origin, destinationLocationCode=dest, departureDate=date, adults=1, max=5, currencyCode='USD')`
   - Find cheapest offer: `min(response.data, key=lambda x: float(x['price']['total']))`
   - Return list of dicts same format as search_cheapest_dates
   - On ResponseError per date, skip that date and continue
   - Log count of successful date lookups

5. **generate_sample_dates(num_dates=12)** function:
   - Generate 12 dates every 2 weeks starting from 6 weeks out, up to 6 months out
   - 12 sample dates (not 6) to provide better coverage when Cheapest Date Search cache misses, which is common for African routes (JFK-LOS, JFK-ACC, etc. are often NOT in the Amadeus cache)
   - This uses more API calls per fallback route (12 vs 6) but is necessary to approximate the full date range that Cheapest Date Search would provide
   - Return list of date strings in YYYY-MM-DD format
   - NOTE: Even with 12 samples, this is best-effort coverage -- not equivalent to the full date range that Cheapest Date Search provides. The Cheapest Date Search cache typically returns 30-60+ dates per route.

6. **get_prices_for_route(client, origin, dest)** function:
   - Try search_cheapest_dates first
   - If returns empty list, fall back to search_offers_fallback with generate_sample_dates()
   - Return tuple: (prices_list, source_str) where source_str is "cheapest_date_search" or "flight_offers_search"
   - Log which source was used

IMPORTANT: Do NOT hand-roll OAuth2 token management. The SDK handles this automatically.
IMPORTANT: Normalize ALL prices to int immediately after retrieval (research Pitfall 6).
IMPORTANT: Do NOT import or call anything from deal_finder.py in this module -- keep it focused on API communication only.

Update `requirements.txt` to add `amadeus>=12.0.0` at the end of the existing dependencies.

<task type="auto">
  <name>Task 2: Create price_tracker.py -- price change detection, caching, and budget tracking</name>
  <files>price_tracker.py</files>
  <action>
Create `price_tracker.py` at project root with a PriceTracker class:

1. **PriceTracker class** with these methods:

   **__init__(self, cache_file="price_cache.json", cooldown_file="alert_cooldown.json")**:
   - Load price cache from JSON (same pattern as deal_finder.py's load_seen_deals)
   - Load alert cooldown state from JSON
   - Initialize api_call_counter = 0 (tracks calls this run)
   - Initialize MONTHLY_BUDGET = 2160 (from research: 6 routes x 12 checks/day x 30 days)
   - Use Path(__file__).parent / filename for file paths (same pattern as deal_finder.py)

   **load_cache(self) -> dict**:
   - Read price_cache.json, return empty dict if missing/corrupt
   - Same try/except pattern as deal_finder.py's load_seen_deals()

   **save_cache(self)**:
   - Write price_cache.json with json.dump(indent=2)

   **load_cooldown(self) -> dict**:
   - Read alert_cooldown.json, return empty dict if missing/corrupt

   **save_cooldown(self)**:
   - Write alert_cooldown.json with json.dump(indent=2)

   **make_cache_key(self, origin, dest) -> str**:
   - Return f"{origin}-{dest}" (route-level, not date-level -- Amadeus returns many dates per route)

   **check_route(self, origin, dest, prices, source) -> list[dict]**:
   - Takes prices list from amadeus_client.get_prices_for_route() and source string
   - For each price entry, classify using deal_finder.classify_deal(price_usd, dest)
   - Compare against cached prices for same route
   - Build list of deal candidates: dicts with {origin, dest, dest_name, price, departure_date, return_date, tier, label, normal_price, source}
   - Update cache with latest prices for the route (cache key -> {best_price, checked_at, source, prices_count})
   - Import and call log_price_search() from deal_finder for each price observation (pass source as "amadeus_cheapest_date" or "amadeus_offers_search")
   - Return only NEW deals (deals where the tier has not been alerted for this route in the cooldown window)
   - Get dest_name from deal_finder.DESTINATIONS[dest]["name"]

   **is_on_cooldown(self, origin, dest, tier) -> bool**:
   - Check alert_cooldown for key f"{origin}-{dest}-{tier}"
   - If exists and alerted_at is within 24 hours, return True (on cooldown)
   - Otherwise return False
   - Use 24-hour cooldown for all tiers in Phase 1 (Phase 4 will implement tier-specific cooldowns)

   **record_alert(self, origin, dest, tier)**:
   - Set alert_cooldown[f"{origin}-{dest}-{tier}"] = {"alerted_at": datetime.now().isoformat(), "tier": tier}

   **track_api_calls(self, count)**:
   - self.api_call_counter += count
   - Print running total: f"API calls this run: {self.api_call_counter}"

   **get_run_summary(self) -> dict**:
   - Return {api_calls: int, routes_checked: int, deals_found: int, cache_size: int}

IMPORTANT: Import classify_deal, DESTINATIONS, log_price_search from deal_finder.py. Do NOT duplicate deal classification logic.
IMPORTANT: Use the SAME JSON file patterns as deal_finder.py (load/save with try/except, Path-based paths).
IMPORTANT: The cooldown is 24 hours for ALL tiers in Phase 1. Phase 4 will implement the full FSM with tier-specific cooldowns.
