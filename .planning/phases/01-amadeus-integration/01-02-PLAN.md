<objective>
Create the cross-validation module and the monitor coordinator that ties everything together -- the logic layer that ensures no single-source alerts ever reach subscribers.

Purpose: DISC-02 requires cross-validation of ALL Amadeus prices against Google Flights before alerting. This is the safety layer that prevents false alerts from ghost fares or cache staleness. The monitor coordinator orchestrates the full pipeline: fetch prices, detect changes, cross-validate, and alert.

Output: `cross_validator.py` (Amadeus vs fast-flights price comparison) and `amadeus_monitor.py` (the main entry point that runs every 2 hours).
</objective>

  <name>Task 1: Create cross_validator.py -- verify Amadeus prices against Google Flights</name>
  <files>cross_validator.py</files>
  <action>
Create `cross_validator.py` at project root with:

1. **cross_validate_deal(origin, dest, departure_date, amadeus_price_usd)** function:
   - Uses fast-flights to check the same route on Google Flights (same pattern as deal_finder.py's search_flight function)
   - Calculate return_date as departure_date + 10 days (matching deal_finder.py's TRIP_LENGTH_DAYS)
   - Call get_flights() with FlightData for outbound and return legs, round-trip, economy, 1 adult
   - Parse all prices using deal_finder.parse_price()
   - Find google_min = min of parsed prices
   - Apply 15% tolerance for cross-validation (from research):
     * If amadeus_price is within 15% of google_min: VALIDATED (prices agree)
     * If amadeus_price < google_min: VALIDATED (Amadeus found better deal -- this is fine)
     * If amadeus_price > google_min by more than 15%: NOT VALIDATED (Amadeus price suspicious)
   - Build the Google Flights URL via build_google_flights_url(origin, dest, departure_date, return_date)
   - Return a dict: {"validated": bool, "amadeus_price": int, "google_price": int|None, "tolerance_pct": 15, "source": "fast_flights", "google_url": str}
   - On ANY exception from fast-flights, return {"validated": False, "amadeus_price": amadeus_price, "google_price": None, "error": str(e), "google_url": build_google_flights_url(origin, dest, departure_date, return_date)}
   - Log: f"Cross-validate {origin}-{dest} {departure_date}: Amadeus ${amadeus_price} vs Google ${google_min} -> {'PASS' if validated else 'FAIL'}"

2. **CROSS_VALIDATION_TOLERANCE** constant = 0.15 (15%)

3. **build_google_flights_url(origin, dest, departure_date, return_date)** function:
   - Builds a direct Google Flights URL for the deal (same pattern as deal_finder.py line 394-397)
   - Return the URL string
   - This URL is included in the email alert so subscribers can book

IMPORTANT: Import FlightData, Passengers, get_flights from fast_flights (same as deal_finder.py).
IMPORTANT: Import parse_price from deal_finder (do NOT duplicate price parsing logic).
IMPORTANT: If fast-flights fails for ANY reason, return validated=False. The monitor must NOT alert when cross-validation cannot be performed (research: "Never alert on single-source data").
IMPORTANT: Add time.sleep(random.uniform(0.5, 1.5)) before the fast-flights call to avoid rate limiting (same pattern as deal_finder.py).
IMPORTANT: ALWAYS include google_url in the return dict, even on failure -- the URL is built from inputs (origin/dest/dates), not from fast-flights results, so it is always available.

<task type="auto">
  <name>Task 2: Create amadeus_monitor.py -- priority route monitoring coordinator</name>
  <files>amadeus_monitor.py</files>
  <action>
Create `amadeus_monitor.py` at project root as the main entry point for priority route monitoring:

1. **Imports:**
   - from amadeus_client import create_amadeus_client, get_prices_for_route, PRIORITY_ROUTES
   - from price_tracker import PriceTracker
   - from cross_validator import cross_validate_deal, build_google_flights_url
   - from deal_finder import classify_deal, send_email, log_price_search, DESTINATIONS
   - Standard lib: datetime, time, random, os, json

2. **monitor_priority_routes()** function (the core logic):
   - Create Amadeus client via create_amadeus_client()
   - Create PriceTracker instance
   - Initialize empty list for validated_deals
   - For each (origin, dest) in PRIORITY_ROUTES:
     a. Print f"[{i}/{len(PRIORITY_ROUTES)}] Checking {origin}-{dest}..."
     b. Call get_prices_for_route(client, origin, dest) -> (prices, source)
     c. Track API calls via tracker.track_api_calls(len(prices) if source == "flight_offers_search" else 1)
     d. Call tracker.check_route(origin, dest, prices, source) -> deal_candidates
     e. For each deal candidate:
        - Call cross_validate_deal(origin, dest, deal["departure_date"], deal["price"])
        - **If validated (validation_result["validated"] == True):**
          * Set deal["url"] = validation_result["google_url"]
          * Add deal to validated_deals
          * Record alert cooldown: tracker.record_alert(origin, dest, deal["tier"])
        - **If NOT validated (validation_result["validated"] == False):**
          * Log: f"Deal {origin}-{dest} ${deal['price']} on {deal['departure_date']} NOT cross-validated, skipping alert"
          * Price cache IS already updated (tracker.check_route updated it above) -- this is correct because we did observe the price from Amadeus
          * Do NOT record alert cooldown (no alert was sent, so the deal is eligible for re-check next run)
          * Log the failed observation for debugging: call log_price_search() with source="amadeus_FAILED_VALIDATION" so the price history records it happened but distinguishes it from validated observations
     f. Sleep random.uniform(1, 3) between routes (rate limiting)
   - Save tracker state (cache + cooldown)
   - Return validated_deals

3. **format_deals_for_email(validated_deals)** function:
   - Transform validated_deals into the format expected by deal_finder.send_email()
   - Each deal dict must have: origin, dest, dest_name, region, price, tier, label, normal_price, departure, return, url, lowest_found, highest_found, weeks_searched
   - **Explicit field mapping (deal -> email format):**
     * `"departure"`: `deal["departure_date"]` (Amadeus returns as YYYY-MM-DD string)
     * `"return"`: `deal["return_date"]` (Amadeus returns as YYYY-MM-DD string)
     * `"url"`: `deal["url"]` (Google Flights URL set in monitor_priority_routes from validation_result["google_url"] via build_google_flights_url())
     * `"origin"`: `deal["origin"]`
     * `"dest"`: `deal["dest"]`
     * `"dest_name"`: `deal["dest_name"]`
     * `"region"`: `DESTINATIONS[deal["dest"]]["region"]`
     * `"price"`: `deal["price"]`
     * `"tier"`: `deal["tier"]`
     * `"label"`: `deal["label"]`
     * `"normal_price"`: `deal["normal_price"]`
     * `"lowest_found"`: `deal["price"]` (single price observation from Amadeus)
     * `"highest_found"`: `deal["price"]` (single price observation from Amadeus)
     * `"weeks_searched"`: `1` (Amadeus returns specific dates, not weekly scans)
   - Return list of formatted deal dicts

4. **main()** function:
   - Print banner: "Detty Priority Monitor (Amadeus) - {datetime}"
   - Print "Routes: {len(PRIORITY_ROUTES)} priority routes"
   - Print "Cross-validation: enabled (15% tolerance)"
   - Call monitor_priority_routes()
   - If validated deals found:
     * Format for email via format_deals_for_email()
     * Call deal_finder.send_email(formatted_deals)
     * Print f"Sent {len(deals)} validated deals to subscribers"
   - Else: Print "No validated deals this run."
   - Print run summary from tracker.get_run_summary()
   - Print f"Completed at {datetime.now()}"

5. **if __name__ == "__main__": main()**

IMPORTANT: NEVER call send_email with deals that have NOT been cross-validated. This is the core safety guarantee of DISC-02.
IMPORTANT: If create_amadeus_client() raises (missing credentials), catch the error and exit with a clear message: "Amadeus credentials not configured. Set AMADEUS_CLIENT_ID and AMADEUS_CLIENT_SECRET."
IMPORTANT: Use deal_finder.send_email() for email delivery -- do NOT create a separate email path. This ensures Google Sheets subscribers and Gmail SMTP are used consistently.
IMPORTANT: The deal dict format must match what deal_finder.send_email() / build_email_content() expects. Check deal_finder.py lines 559-675 for the expected fields.
IMPORTANT: Failed cross-validation behavior is: (a) price cache IS updated (already happened in check_route), (b) alert cooldown is NOT recorded (no alert sent), (c) log_price_search IS called with source="amadeus_FAILED_VALIDATION" for debugging.
