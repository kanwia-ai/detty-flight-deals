  Create subscriber/reminders.py for quarterly payment reminders.

  send_payment_reminders() -> dict:
    """Send payment reminders to premium subscribers approaching expiry.

    Checks for subscribers whose premium_expiry is within 7 days.
    Sends reminder email with Venmo/Zelle payment instructions.
    Updates payment_reminder_sent timestamp after sending.

    Returns: {"reminders_sent": N, "errors": N}
    """
    - Import TursoClient, send_to_subscriber from mvp0_sender
    - db = TursoClient()
    - If not db._turso_available: return zeros

    - Get subscribers needing reminder: db.get_subscribers_needing_reminder(days_before=7)
    - If none, print "No payment reminders needed" and return zeros

    - For each subscriber:
      - Build reminder email:
        subject = "Your Detty Premium subscription renews soon"
        - Calculate days_until_expiry from premium_expiry
        - HTML body with:
          - Detty branding header (same gradient as other emails)
          - Greeting: "Hey {name}!"
          - Message: "Your Detty Premium subscription expires in {days} days (on {expiry_date})."
          - What you'll lose section:
            - Instant WOW/mistake fare alerts
            - SMS notifications for mistake fares
            - Historical price context
            - Unlimited metro preferences
          - Payment instructions:
            - "$15 for another quarter ($5/month)"
            - "Venmo: @DettyFlightDeals"
            - "Zelle: dettyflightdeals@gmail.com"
          - "Once you've sent payment, reply to this email and we'll renew your subscription."
          - Standard Detty footer
        - Plain text version with same info

      - Send via send_to_subscriber
      - If success: update payment_reminder_sent = now via db.update_subscriber
      - Track sent/errors

    - Print summary and return dict

  Also send a 1-day-before reminder (more urgent):
    - Get subscribers with premium_expiry within 1 day AND payment_reminder_sent > 6 days ago
    - (The get_subscribers_needing_reminder query already handles this with the 6-day gap)
    - Same email but with more urgency: "LAST DAY: Your Premium expires tomorrow"

<task type="auto">
  <name>Task 2: Create weekly digest GitHub Actions workflow</name>
  <files>.github/workflows/weekly_digest.yml</files>
  <action>
  Create .github/workflows/weekly_digest.yml following the patterns in existing workflows (priority_monitor.yml, find_deals.yml).

  Workflow spec:

  name: Weekly Free Tier Digest

  on:
    schedule:
      - cron: '0 14 * * 0'  # Sunday 2PM UTC = 10AM ET / 7AM PT
    workflow_dispatch:        # Manual trigger for testing

  concurrency:
    group: "detty-state-commit"  # Match existing pattern to prevent git conflicts
    cancel-in-progress: false    # Queue runs, don't drop

  jobs:
    weekly-digest:
      runs-on: ubuntu-latest
      steps:
        - name: Checkout code
          uses: actions/checkout@v4

        - name: Set up Python
          uses: actions/setup-python@v5
          with:
            python-version: '3.11'

        - name: Install dependencies
          run: pip install -r requirements.txt

        - name: Check Turso connection
          continue-on-error: true
          env:
            TURSO_DATABASE_URL: ${{ secrets.TURSO_DATABASE_URL }}
            TURSO_AUTH_TOKEN: ${{ secrets.TURSO_AUTH_TOKEN }}
          run: |
            python -c "from db import TursoClient; c = TursoClient(); print(f'Turso: {\"connected\" if c._turso_available else \"unavailable\"}')"

        - name: Generate and send weekly digest
          env:
            TURSO_DATABASE_URL: ${{ secrets.TURSO_DATABASE_URL }}
            TURSO_AUTH_TOKEN: ${{ secrets.TURSO_AUTH_TOKEN }}
            SMTP_EMAIL: ${{ secrets.SMTP_EMAIL }}
            SMTP_PASSWORD: ${{ secrets.SMTP_PASSWORD }}
            GOOGLE_SHEET_ID: ${{ secrets.GOOGLE_SHEET_ID }}
            GOOGLE_SHEETS_CREDS: ${{ secrets.GOOGLE_SHEETS_CREDS }}
          run: python -m subscriber.digest

        - name: Send payment reminders
          env:
            TURSO_DATABASE_URL: ${{ secrets.TURSO_DATABASE_URL }}
            TURSO_AUTH_TOKEN: ${{ secrets.TURSO_AUTH_TOKEN }}
            SMTP_EMAIL: ${{ secrets.SMTP_EMAIL }}
            SMTP_PASSWORD: ${{ secrets.SMTP_PASSWORD }}
          run: python -m subscriber.reminders

  Notes:
  - Use the same concurrency group as priority_monitor.yml ("detty-state-commit")
  - Include all env vars that subscriber code might need
  - Turso connection check as separate step with continue-on-error (matches Phase 2 pattern)
  - Payment reminders run after digest (both in same job, sequential)
  - No Twilio env vars in this workflow (Twilio is used by deal_finder during instant alerts, not in digest)
  - GOOGLE_SHEET_ID and GOOGLE_SHEETS_CREDS included for migration period fallback
  </action>
  <verify>

  If yaml not installed, verify manually: the file should have "cron: '0 14 * * 0'" and "python -m subscriber.digest" in it.
  Alternatively: grep -c "subscriber.digest" .github/workflows/weekly_digest.yml (should return 1)
