<task type="auto">
  <name>Task 1: Create SubscriberManager class with CRUD and metro change enforcement</name>
  <files>subscriber/manager.py, subscriber/__init__.py</files>
  <action>
  Create subscriber/manager.py with a SubscriberManager class that wraps TursoClient subscriber operations with business logic.

  Constructor: __init__(self, db_client=None)
    - Accepts a TursoClient instance (or creates one if None)
    - Store as self.db

  Methods:

  get_all_active(self, tier: str = None) -> list[dict]:
    Delegates to self.db.get_active_subscribers(tier).
    Returns list of subscriber dicts.

  get_by_email(self, email: str) -> dict | None:
    Query subscribers WHERE email = ? AND active = 1.
    Uses self.db._conn directly (simple query, matches existing pattern in client.py).
    Returns dict or None.

  add(self, email: str, name: str = None, tier: str = "free", metro_group: str = None, start_trial: bool = True) -> dict:
    Calls self.db.add_subscriber(email, name, tier, metro_group).
    If start_trial is True and tier is "free", automatically start a 7-day trial
    by calling trial.start_trial(self, email) (imported from subscriber.trial).
    Returns the newly created subscriber dict (via get_by_email).
    If email already exists (INSERT OR IGNORE), returns existing subscriber.

  deactivate(self, email: str) -> bool:
    Sets active = 0 via self.db.update_subscriber(email, active=0).
    Returns True/False.

  update_metro(self, email: str, new_metro: str) -> tuple[bool, str]:
    Get subscriber via get_by_email.
    If subscriber is None, return (False, "Subscriber not found").
    If subscriber["tier"] == "free":
      Check metro_change_date. If set and less than 30 days ago, return (False, "Metro can only be changed once per month").
      Otherwise: update metro_group = new_metro, metro_change_date = datetime('now').
    If subscriber["tier"] in ("premium", "trial"):
      Update freely (no rate limit per CONTEXT.md).
      Parse metro_groups_json, add new_metro if not present, save back.
    Return (True, "Metro updated").

  set_premium(self, email: str, months: int = 3) -> bool:
    Update tier = "premium", premium_start = now, premium_expiry = now + months months.
    Clear trial fields (trial_start=None, trial_expiry=None).
    Return True/False.

  set_premium_metros(self, email: str, metros: list[str]) -> bool:
    Update metro_groups_json = json.dumps(metros).
    Return True/False.

  set_dest_regions(self, email: str, regions: list[str]) -> bool:
    Update dest_regions_json = json.dumps(regions).
    Return True/False.

  set_phone(self, email: str, phone: str) -> bool:
    Update phone = phone.
    Return True/False.

  Update subscriber/__init__.py to also export SubscriberManager:
    from .manager import SubscriberManager
  </action>

  </done>

  1. Create subscriber/trial.py with trial lifecycle functions:

  start_trial(manager, email: str) -> bool:
    - Import SubscriberManager type for type hint (or use duck typing)
    - Calculate trial_expiry = datetime.now() + timedelta(days=7)
    - Update subscriber: tier="trial", trial_start=now.isoformat(), trial_expiry=trial_expiry.isoformat()
    - Log: "[TRIAL] Started 7-day trial for {email}, expires {trial_expiry}"
    - Return True/False

  check_trial_expiry(manager, email: str) -> bool:
    - Get subscriber via manager.get_by_email(email)
    - If subscriber is None or tier != "trial", return False (no action needed)
    - If trial_expiry is None, return False
    - If datetime.fromisoformat(trial_expiry) <= datetime.now():
      - Downgrade: update tier="free", clear trial_start and trial_expiry
      - Log: "[TRIAL] Expired trial for {email}, downgraded to free"
      - Return True (expired and downgraded)
    - Return False (still active)

  expire_all_trials(manager) -> int:
    - Get all active subscribers with tier="trial"
    - For each, call check_trial_expiry(manager, email)
    - Return count of expired trials
    - This is called lazily during routing, not on a separate cron

  is_trial_active(subscriber: dict) -> bool:
    - If subscriber["tier"] != "trial", return False
    - If subscriber["trial_expiry"] is None, return False
    - Return datetime.fromisoformat(subscriber["trial_expiry"]) > datetime.now()

  2. Create subscriber/migration.py as a runnable script (python -m subscriber.migration):

    - Log summary: "Migrated: {N}, Skipped: {N}, Total in Turso: {N}"
    - Return {"migrated": N, "skipped": N, "total": N}
