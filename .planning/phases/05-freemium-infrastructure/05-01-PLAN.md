  <name>Task 2: Create metro group mappings and subscriber CRUD methods</name>
  <files>subscriber/__init__.py, subscriber/metro_groups.py, db/client.py</files>
  <action>
  1. Create subscriber/ package directory with __init__.py that exports:
     - from .metro_groups import METRO_GROUPS, AIRPORT_TO_METRO, DEST_REGIONS

  2. Create subscriber/metro_groups.py with:

     METRO_GROUPS dict mapping metro names to airport code lists:
       "NYC": ["JFK", "EWR"]
       "DC": ["IAD"]
       "ATL": ["ATL"]
       "HOU": ["IAH"]
       "CHI": ["ORD"]
       "LA": ["LAX"]
       "DFW": ["DFW"]
       "BOS": ["BOS"]

     NOTE: DFW and BOS are added per RESEARCH.md recommendation. They are in the current ORIGINS list and serve real diaspora populations.

     AIRPORT_TO_METRO reverse mapping dict (airport code -> metro name), built programmatically from METRO_GROUPS.

     DEST_REGIONS dict mapping region names to destination airport codes:
       "West": ["LOS", "ABV", "ACC", "DSS", "FNA", "ABJ", "LFW", "COO"]
       "Central": ["DLA", "NSI", "FIH"]
       "East": ["NBO", "ADD"] (future expansion - Nairobi, Addis Ababa)
       "Southern": ["JNB", "CPT"] (future expansion - Johannesburg, Cape Town)
       "North": ["CAI", "CMN"] (future expansion - Cairo, Casablanca)

     DEST_TO_REGION reverse mapping dict (dest airport code -> region name).

     Helper function get_subscriber_metros(subscriber: dict) -> list[str]:
       If subscriber["tier"] in ("premium", "trial") and subscriber["metro_groups_json"]:
         Return json.loads(subscriber["metro_groups_json"])
       Elif subscriber["metro_group"]:
         Return [subscriber["metro_group"]]
       Else:
         Return list(METRO_GROUPS.keys()) -- all metros (no preference = all)

     Helper function get_airports_for_metros(metros: list[str]) -> set[str]:
       Return the union of METRO_GROUPS[m] for each m in metros.

     Helper function airport_matches_subscriber(airport_code: str, subscriber: dict) -> bool:
       Get subscriber metros via get_subscriber_metros(subscriber).
       Get airports via get_airports_for_metros(metros).
       Return airport_code in airports.
       Log a warning if airport_code is not in AIRPORT_TO_METRO.

  3. Extend TursoClient in db/client.py with these new methods (follow existing patterns exactly -- check _turso_available, use _execute_with_fallback, commit+sync):

     get_active_subscribers(self, tier: str = None) -> list[dict]:
       Query subscribers WHERE active = 1 (and tier = ? if provided).
       Convert rows to dicts using PRAGMA table_info for column names.
       Return empty list on failure.

     add_subscriber(self, email: str, name: str = None, tier: str = "free", metro_group: str = None) -> bool:
       INSERT OR IGNORE into subscribers (email, name, tier, metro_group).
       commit + sync. Return True/False via _execute_with_fallback.

     update_subscriber(self, email: str, **kwargs) -> bool:
       Build dynamic UPDATE SET clause from kwargs (only known column names).
       Always set updated_at = datetime('now').
       WHERE email = ?. commit + sync. Return True/False.

     queue_deal_for_digest(self, deal: dict) -> bool:
       INSERT into digest_queue (route, origin, dest, dest_name, price_cents, tier, deal_data_json).
       deal_data_json = json.dumps(deal). commit + sync. Return True/False.

     get_pending_digest_deals(self, max_age_days: int = 7) -> list[dict]:
       SELECT from digest_queue WHERE digest_sent = 0 AND found_at >= datetime('now', '-{max_age_days} days').
       ORDER BY tier DESC (wow/mistake first), found_at DESC.
       Convert to dicts. Return empty list on failure.

     mark_digest_deals_sent(self, deal_ids: list[int]) -> bool:
       UPDATE digest_queue SET digest_sent = 1 WHERE id IN (...).
       commit + sync. Return True/False.

     get_subscribers_needing_reminder(self, days_before: int = 7) -> list[dict]:
       SELECT from subscribers WHERE tier = 'premium' AND active = 1
       AND premium_expiry IS NOT NULL
       AND premium_expiry <= datetime('now', '+{days_before} days')
       AND (payment_reminder_sent IS NULL OR payment_reminder_sent < datetime('now', '-6 days')).
       Convert to dicts. Return empty list on failure.
  </action>
