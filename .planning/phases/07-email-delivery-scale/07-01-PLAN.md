Create `email_client.py` at project root with:

1. **Resend SDK initialization:**
   - `resend.api_key = os.environ.get("RESEND_API_KEY", "")`
   - `SEND_DOMAIN = os.environ.get("SEND_DOMAIN", "dettyflightdeals.com")`

2. **`send_email(to, subject, html_body, plain_body, reply_to=None, headers=None, tags=None) -> dict`:**
   - If `resend.api_key` is falsy, call `_send_via_gmail_smtp(to, subject, html_body, plain_body)` and return `{"id": None, "provider": "gmail_smtp"}`
   - Otherwise, build `resend.Emails.SendParams` dict with `from`, `to` (list), `subject`, `html`, `text`
   - Add `reply_to`, `headers`, `tags` if provided
   - Call `resend.Emails.send(params)` inside try/except
   - On success: return `{"id": result.get("id") if isinstance(result, dict) else getattr(result, "id", None), "provider": "resend"}`
   - On exception: log warning, fall back to `_send_via_gmail_smtp()`, return `{"id": None, "provider": "gmail_smtp_fallback"}`

3. **`_send_via_gmail_smtp(to, subject, html_body, plain_body) -> dict`:**
   - Reuse exact Gmail SMTP logic from current `mvp0_sender.py:send_to_subscriber()` (SMTP_SSL to smtp.gmail.com:465)
   - Return `{"id": None, "provider": "gmail_smtp"}`
   - On failure: raise the exception (let caller handle)

4. **`generate_unsubscribe_token(email: str) -> str`:**
   - `UNSUBSCRIBE_SECRET = os.environ.get("UNSUBSCRIBE_SECRET", "default-dev-secret")`
   - Use `hmac.new(UNSUBSCRIBE_SECRET.encode(), email.lower().strip().encode(), hashlib.sha256).hexdigest()[:32]`

5. **`get_unsubscribe_headers(email: str) -> dict`:**
   - `UNSUBSCRIBE_BASE_URL = os.environ.get("UNSUBSCRIBE_BASE_URL", "https://unsubscribe.dettyflightdeals.com")`
   - Build token via `generate_unsubscribe_token(email)`
   - Return `{"List-Unsubscribe": f"<{url}>", "List-Unsubscribe-Post": "List-Unsubscribe=One-Click"}`

6. **`send_to_subscriber(to, subject, html_body, plain_body) -> bool`:**
   - Convenience wrapper matching mvp0_sender signature for backward compatibility
   - Calls `get_unsubscribe_headers(to)` to build headers
   - Calls `send_email(to, subject, html_body, plain_body, headers=unsub_headers)`
   - Returns True on success, False on exception (with logging)

Add `resend>=2.21.0` to `requirements.txt` under a `# Email delivery (Phase 7)` comment.
