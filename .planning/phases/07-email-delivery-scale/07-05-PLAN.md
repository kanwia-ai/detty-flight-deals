<task type="checkpoint:human-action" gate="blocking">
  <name>Task 1: Domain and DNS setup</name>
  <action>
Complete the following setup steps (Claude cannot do these -- they require account access and DNS management):

**Step 1: Resend Account Setup**
1. Go to https://resend.com and create an account (or log in)
2. Go to Domains -> Add Domain -> enter `dettyflightdeals.com`
3. Resend will show DNS records to add. Copy them.

**Step 2: DNS Configuration**
Add these records to your DNS provider (Cloudflare, Namecheap, etc.):

1. **SPF record** (TXT):
   - Name: `@` (or as Resend specifies)
   - Value: Copy exactly from Resend dashboard (typically `v=spf1 include:amazonses.com ~all`)

2. **DKIM records** (CNAME -- typically 3 records):
   - Copy all CNAME records from Resend dashboard exactly as shown

3. **DMARC record** (TXT):
   - Name: `_dmarc`
   - Value: `v=DMARC1; p=none; rua=mailto:dettyflightdeals@gmail.com`
   - Start with `p=none` (monitoring mode). Change to `p=quarantine` after 2 weeks of clean delivery.

**Step 3: Wait for DNS Propagation**
- Resend will auto-verify. Check "Domains" page for green checkmark.
- This can take 5 minutes to 72 hours. Usually < 1 hour.

**Step 4: Get API Key**
1. Resend Dashboard -> API Keys -> Create API Key
2. Copy the key (starts with `re_`)

**Step 5: Add GitHub Secrets**
```bash
gh secret set RESEND_API_KEY
# Paste the API key

gh secret set UNSUBSCRIBE_SECRET
# Generate a random secret: openssl rand -hex 32

# Add repository variables (not secrets -- these aren't sensitive)
gh variable set SEND_DOMAIN --body "dettyflightdeals.com"
gh variable set UNSUBSCRIBE_BASE_URL --body "https://unsubscribe.dettyflightdeals.com"
```

**Step 6: Deploy Cloudflare Worker**
```bash
cd unsubscribe-worker
npm install
wrangler secret put UNSUBSCRIBE_SECRET
# Paste the SAME secret as GitHub (must match for HMAC tokens)
wrangler secret put TURSO_URL
# Paste your Turso database HTTP URL
wrangler secret put TURSO_TOKEN
# Paste your Turso auth token
wrangler deploy
```

**Step 7: Configure Worker Route (if using custom domain)**
In Cloudflare Dashboard -> Workers Routes, map `unsubscribe.dettyflightdeals.com/*` to the worker.
Or use Cloudflare Workers custom domain feature.
