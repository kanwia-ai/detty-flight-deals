<objective>
Replace all mailto: unsubscribe links with HTTPS unsubscribe URLs and ensure List-Unsubscribe headers are sent with every email.

Purpose: Gmail/Yahoo require RFC 8058 one-click unsubscribe (List-Unsubscribe + List-Unsubscribe-Post headers) and a visible HTTPS unsubscribe link in the email body. Current implementation uses mailto: links which are non-compliant. This plan updates all 6 files that contain unsubscribe links.

Output: All email templates use HTTPS unsubscribe URLs with HMAC tokens. email_client.py automatically injects List-Unsubscribe headers on every send.
</objective>
