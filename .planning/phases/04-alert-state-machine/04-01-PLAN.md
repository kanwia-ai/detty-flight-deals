AlertState Enum (5 states from RESEARCH.md):
```python
class AlertState(Enum):
    NORMAL = auto()           # No active deal
    GREAT_ALERTING = auto()   # Great deal detected, will alert
    GREAT_ALERTED = auto()    # Great deal, already alerted
    WOW_ALERTING = auto()     # WOW deal detected, will alert
    WOW_ALERTED = auto()      # WOW deal, already alerted
```

RouteState dataclass:
- route: str
- state: AlertState (default NORMAL)
- last_alert_tier: Optional[str]
- last_alert_price_cents: Optional[int]
- consecutive_normal: int (default 0)

AlertStateMachine class:
- RESET_THRESHOLD = 3 (consecutive normal prices to reset cycle)
- TRANSITIONS dict mapping (state, event) -> (new_state, should_alert)
  Per CONTEXT.md decisions:
  - NORMAL + great_deal -> GREAT_ALERTING (alert)
  - NORMAL + wow_deal -> WOW_ALERTING (alert)
  - GREAT_ALERTED + great_deal -> GREAT_ALERTED (no re-alert)
  - GREAT_ALERTED + wow_deal -> WOW_ALERTING (escalation alert!)
  - WOW_ALERTED + wow_deal -> WOW_ALERTED (no re-alert)
  - WOW_ALERTED + great_deal -> GREAT_ALERTED (de-escalation, silent)
  - Any ALERTED + normal -> check consecutive count for reset

- __init__(self, db_client=None): Accept optional TursoClient
- get_state(route: str) -> RouteState: Load from DB or create new
- _save_state(state: RouteState): Persist to DB
- process(route, deal_tier, price_cents, is_mistake_fare=False, normal_price_cents=None) -> (should_alert, alert_info)
  - Maps deal_tier to event (wow/great/normal)
  - Mistake fares always map to wow_deal event
  - Looks up transition
  - Tracks consecutive normal count for reset
  - Returns alert_info dict with tier, tier_emoji, price, is_escalation, etc.

- _get_tier_emoji(tier, is_mistake_fare) -> str:
  - Great -> "*"
  - WOW -> "**"
  - MISTAKE -> "!!"
  (Per RESEARCH.md: text-compatible indicators)

Key behaviors per CONTEXT.md:
- Two tiers only (Great, WOW) - "good" tier from anomaly detection maps to Great
- Mistake fares always treated as WOW-level (premium content)
- De-escalation is SILENT (no alert on WOW->Great or Great->Normal)
- Escalation OVERRIDES - Great->WOW always alerts
- Reset after 3 consecutive normal prices
