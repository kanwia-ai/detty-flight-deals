  ```python
  def make_cache_key(self, origin: str, dest: str, cabin_class: str = "economy") -> str:

          return f"{origin}-{dest}"  # Backward compatible
      return f"{origin}-{dest}:{cabin_class.upper()}"
  ```

  This is backward compatible — economy keys stay unchanged. Only premium cabin keys get the `:CABIN` suffix.

  Do NOT modify `check_route()` in this task — the premium cabin monitor (Plan 02) will handle its own check logic. The cache key change is purely to support the new key format.
